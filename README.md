# Augusto Alves Brasil — Portfólio pessoal

Site estático (HTML/CSS/JS puro, sem build) do portfólio pessoal de
Augusto Alves Brasil — Product Design & UX Engineering.

## Estrutura

- `index.html` — página única, todas as seções
- `logo-wordmark.png` / `logo-wordmark-light.png` — logo CriAugu no nav (dark/light)

## Deploy

Site 100% estático — qualquer hospedagem que sirva arquivos HTML funciona.
Sem dependências, sem etapa de build.

## Tema

Light/dark via toggle no nav, com preferência salva em `localStorage` e
fallback para `prefers-color-scheme` do navegador.
